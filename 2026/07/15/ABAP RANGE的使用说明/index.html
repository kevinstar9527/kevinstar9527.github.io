ABAP RANGE 的使用说明

ABAP RANGE 简述

ABAP中的Range是一种用于处理数据范围的结构，通常与SAP R/3系统的标准内表一起使用。在ABAP编程中，Range可以用于定义和操作数据的范围，以便进行条件筛选、变式判断等操作。使用Range可以提高取数效率和程序性能。

RANGE的结构解析

SIGN

SIGN字段用于指定范围符号，可以取’I’ （include）或’E’ (exclude)，分别表示包含在区间内和区间外。

OPTION

OPTION字段用于指定操作选项

  • 等于( EQ )

  • 不等于( NE )

  • 大于( GT )

  • 在范围之间（BT）

  • 小于( LT )

  • 小于等于( LE )

LOW

用于指定范围的上边界

HIGH

用于指定范围的下边界
